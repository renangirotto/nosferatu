## States

### Open

The native `open` attribute renders the panel already open.

```astro title=".astro" frame="terminal"
<Accordion summary="Open from the start" color="green" open>
	Visible on first paint.
</Accordion>
```

<div class="not-content demo demo--stack">

		Visible on first paint.
	</Accordion>

### Grouped

Accordions sharing the native `name` attribute form a group: opening one closes the others.

```astro title=".astro" frame="terminal"
<Accordion summary="Does it need JavaScript?" name="faq">
	No. The toggle and the grouping are the browser's.
</Accordion>
<Accordion summary="How do I group them?" name="faq">
	Give every accordion in the group the same name.
</Accordion>
<Accordion summary="Can a group span a page?" name="faq">
	Yes, the browser matches on the name.
</Accordion>
```

## Icons

By default the summary ends with a plus that turns into a minus when open. The library supplies both, so there is nothing to install. Replace them with any component through `iconCollapsed` and `iconExpanded`:

```astro title=".astro" frame="terminal"
---
import Accordion from 'astro-nosferatu/components/Accordion.astro';
import ArrowDown from 'iconoir/icons/nav-arrow-down.svg';
import ArrowUp from 'iconoir/icons/nav-arrow-up.svg';
---

<Accordion summary="Default icons" color="purple">Panel body.</Accordion>
<Accordion summary="Custom icons" color="purple" iconCollapsed={ArrowDown} iconExpanded={ArrowUp}>
	Panel body.
</Accordion>
```

## Props

| Prop            | Type                                                                                           | Required | Default      |
| --------------- | ---------------------------------------------------------------------------------------------- | -------- | ------------ |
| `summary`       | `string`                                                                                       | Yes      | —            |
| `color`         | `'blue' \| 'cyan' \| 'green' \| 'grey' \| 'orange' \| 'pink' \| 'purple' \| 'red' \| 'yellow'` | No       | grey (unset) |
| `iconCollapsed` | component                                                                                      | No       | plus         |
| `iconExpanded`  | component                                                                                      | No       | minus        |

Every other `<details>` attribute passes through to the element. The default slot is the content disclosed when the accordion opens.

## CSS Variables

| Variable                             | Description                               |
| ------------------------------------ | ----------------------------------------- |
| `--nf-accordion-color`               | Background color of the summary and panel |
| `--nf-accordion-accent-color`        | Text, icon and focus outline color        |
| `--nf-accordion-shadow-color`        | Color of the shadow under the accordion   |
| `--nf-accordion-rule-color`          | Color of the line under an open summary   |
| `--nf-accordion-icon-size`           | Size of the icons                         |
| `--nf-accordion-border-width`        | Width of the rule and the focus outline   |
| `--nf-accordion-transition-duration` | Duration of the hover and press animation |
| `--nf-accordion-disclosure-duration` | Duration of the open and close animation  |

### Theming

Set the variables in a class from a global stylesheet and pass it to the component. Leave `color` out: a `color` sets its own values, which win over the class.

```css title=".css" frame="terminal"
.themed-accordion {
	--nf-accordion-color: var(--nf-green-l-20);
	--nf-accordion-accent-color: var(--nf-blue-l-90);
	--nf-accordion-shadow-color: var(--nf-blue-l-70);
}
```

```astro title=".astro" frame="terminal"
<Accordion class="themed-accordion" summary="Themed">
	Panel body.
</Accordion>
```
