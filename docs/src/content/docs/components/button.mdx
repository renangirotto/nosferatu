A raised button built on the native `<button>` element. It sinks when hovered and presses flat when clicked.

Every component is built for both light and dark color schemes. Switch the site's theme to see this one in each:

<DarkModeSwitch />

## Usage

```astro title=".astro" frame="terminal"
---
import Button from 'astro-nosferatu/components/Button.astro';
---

<Button>Button</Button>
```

## Color variants

You can change the color theme of the component with the `color` prop. If you don't pass it the fallback will be the default grey palette.

```astro title=".astro" frame="terminal"
<Button>Button</Button>
<Button color="blue">Button</Button>
<Button color="cyan">Button</Button>
<Button color="green">Button</Button>
<Button color="grey">Button</Button>
<Button color="orange">Button</Button>
<Button color="pink">Button</Button>
<Button color="purple">Button</Button>
<Button color="red">Button</Button>
<Button color="yellow">Button</Button>
```

## States

### Disabled

The native `disabled` attribute fades the button and stops it from moving.

```astro title=".astro" frame="terminal"
<Button color="green" disabled>Disabled</Button>
```

	<Button color="green" disabled>Disabled</Button>

## Props

| Prop    | Type                                                                                           | Required | Default      |
| ------- | ---------------------------------------------------------------------------------------------- | -------- | ------------ |
| `color` | `'blue' \| 'cyan' \| 'green' \| 'grey' \| 'orange' \| 'pink' \| 'purple' \| 'red' \| 'yellow'` | No       | grey (unset) |
| `type`  | `'button' \| 'submit' \| 'reset'`                                                              | No       | `'button'`   |

Every other `<button>` attribute passes through to the element. The default slot is the button's label.

## CSS Variables

| Variable                          | Description                               |
| --------------------------------- | ----------------------------------------- |
| `--nf-button-color`               | Background color                          |
| `--nf-button-accent-color`        | Text and focus outline color              |
| `--nf-button-shadow-color`        | Color of the shadow under the button      |
| `--nf-button-border-width`        | Width of the focus outline                |
| `--nf-button-transition-duration` | Duration of the hover and press animation |

### Theming

Set the variables in a class from a global stylesheet and pass it to the component. Leave `color` out: a `color` sets its own values, which win over the class.

```css title=".css" frame="terminal"
.themed-button {
	--nf-button-color: var(--nf-green-l-20);
	--nf-button-accent-color: var(--nf-blue-l-90);
	--nf-button-shadow-color: var(--nf-blue-l-70);
}
```

```astro title=".astro" frame="terminal"
<Button class="themed-button">Themed</Button>
```
