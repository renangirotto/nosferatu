## Props

| Prop | Type | Default | Notes |
|---|---|---|---|
| `variant` | `'primary' \| 'secondary'` | `'primary'` | |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Set `type="submit"` inside forms. |

Every other `<button>` attribute (`disabled`, `name`, `aria-*`, `class`, event attributes...) is passed through to the element.

## Theming

The button reads its colors from tokens. Overriding them changes the button, here on a wrapper element:

<div class="not-content demo" style="--nf-red-l-80: var(--nf-green-l-80); --nf-red-l-90: var(--nf-green-l-90);">
	<Button>Themed</Button>
</div>

```astro
<div style="--nf-red-l-80: var(--nf-green-l-80); --nf-red-l-90: var(--nf-green-l-90);">
	<Button>Themed</Button>
</div>
```

## Scoped styles

The button's styles only apply to the button itself. A plain `<button>` next to it is left alone:

<div class="not-content demo">
	<Button>Component</Button>
	<button type="button">Plain button</button>
</div>
