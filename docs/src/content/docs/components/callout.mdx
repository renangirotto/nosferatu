A tinted panel with a title, an optional icon and an optional body, rendered as a `<div>`.

Every component is built for both light and dark color schemes. Switch the site's theme to see this one in each:

## Usage

```astro title=".astro" frame="terminal"
---
import Callout from 'astro-nosferatu/components/Callout.astro';
---

<Callout title="What is a harness?">
	The layer between a model and the world it acts on.
</Callout>
```

## Icons

`icon` takes a component, such as an imported `.svg`. The library ships no icon set: the icons below come from [Iconoir](https://iconoir.com), which this site installs for itself.

```astro title=".astro" frame="terminal"
---
import Callout from 'astro-nosferatu/components/Callout.astro';
import Bell from 'iconoir/icons/bell.svg';
import LightBulb from 'iconoir/icons/light-bulb.svg';
---

<Callout color="orange" title="A bell" icon={Bell}>Body copy.</Callout>
<Callout color="orange" title="A light bulb" icon={LightBulb}>Body copy.</Callout>
<Callout color="orange" title="No icon">Body copy.</Callout>
```

## Props

| Prop    | Type                                                                                           | Required | Default      |
| ------- | ---------------------------------------------------------------------------------------------- | -------- | ------------ |
| `title` | `string`                                                                                       | Yes      | —            |
| `icon`  | component                                                                                      | No       | —            |
| `color` | `'blue' \| 'cyan' \| 'green' \| 'grey' \| 'orange' \| 'pink' \| 'purple' \| 'red' \| 'yellow'` | No       | grey (unset) |

Every other `<div>` attribute passes through to the element. The default slot is the body, shown below the title; leave it out for a title-only callout.

## CSS Variables

| Variable                     | Description                              |
| ---------------------------- | ---------------------------------------- |
| `--nf-callout-surface-color` | Background color                         |
| `--nf-callout-accent-color`  | Title, icon and body text color          |
| `--nf-callout-rule-color`    | Color of the line between title and body |
| `--nf-callout-shadow-color`  | Color of the shadow under the panel      |
| `--nf-callout-shadow`        | The whole shadow, offsets and color      |
| `--nf-callout-icon-size`     | Size of the icon                         |

### Theming

Set the variables in a class from a global stylesheet and pass it to the component. Leave `color` out: a `color` sets its own values, which win over the class.

```css title=".css" frame="terminal"
.themed-callout {
	--nf-callout-surface-color: var(--nf-green-l-20);
	--nf-callout-accent-color: var(--nf-blue-l-90);
	--nf-callout-rule-color: var(--nf-blue-l-90-25);
	--nf-callout-shadow-color: var(--nf-blue-l-100-25);
}
```

```astro title=".astro" frame="terminal"
<Callout class="themed-callout" title="Themed">
	Every color property overridden.
</Callout>
```
